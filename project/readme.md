# Guess the number

# Anh Tran Thi Van

Guess the Number is a simple game where the computer chooses a random number, and the player tries to guess it.

How the game works
The computer generates a random number, for example, between 1 and 100.
The player enters a guess.
The program compares the guess with the secret number:
If the guess is too low, it says "Too low!"
If the guess is too high, it says "Too high!"
If the guess is correct, it says "Correct!"
The player continues guessing until they find the number.
Optionally, the program can count how many attempts the player used.
